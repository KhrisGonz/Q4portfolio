Brute Force

What is a Brute-Force Attack?

A brute-force attack is a method where every possible password is tried until the correct one is found.

Dictionary vs Brute Force

A dictionary attack uses a list of common passwords, making it faster. A brute-force attack tries every possible combination, which takes longer but is more thorough.

Real Example

During a penetration test, a tester might use tools like Hydra to simulate a brute-force attack and check if weak passwords exist.

Defenses

  • Account lockouts after failed attempts
  • Rate limiting login attempts
  • Multi-factor authentication (MFA)

What a Finding Looks Like

If a weak password is discovered, the risk is unauthorized access. The recommendation would be to enforce stronger passwords and enable MFA.
