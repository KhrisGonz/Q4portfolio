SSH

What is SSH?

SSH (Secure Shell) is a protocol that allows you to connect to another computer securely over a network. It encrypts all communication, making it safe from interception.

Why SSH Exists

Before SSH, tools like Telnet sent data in plain text. That meant usernames and passwords could be easily captured. SSH solved this problem by encrypting everything.

Example Command

ssh student@192.168.1.100

student = the account you are logging into
192.168.1.100 = the target machine

What You Can Do After Connecting

Once connected, you can run commands, edit files, install programs, and fully control the remote system — just like you were physically using it.

Why This Matters in Hacking

SSH is often the goal after discovering a system. If an attacker gains access, they can take full control. Ethical hackers test whether this access is properly secured.
