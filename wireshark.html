Wireshark

What is a Packet?

A packet is a small piece of data sent across a network. Think of it like a digital envelope carrying information from one computer to another.

What Does Wireshark Do?

Wireshark captures and displays these packets in real time. It allows you to see exactly what data is being sent across a network.

Real Scenario

If a user logs into a website using HTTP instead of HTTPS, their username and password can be sent in plain text.

What Wireshark Would Show

A tester could see the login request and read the credentials directly from the captured packets.

Why This Matters

This shows why encryption is critical. Ethical hackers use Wireshark to find insecure data transmission and report it.
