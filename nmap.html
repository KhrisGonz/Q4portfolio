Nmap

What is Nmap?

Nmap is a network scanning tool used to discover devices on a network and identify what services they are running.

What Are Ports?

Ports are like doors into a system. Each service (like a website or database) runs on a specific port. If a port is open, it means something is listening — and that could be a target.

Example Scan

nmap -sV 192.168.1.0/24

Sample Output

22/tcp open ssh
80/tcp open http

Port 22 shows SSH is available. Port 80 shows a web server is running. These results tell a tester where to focus next.

Why This Matters

Nmap is usually the first step in a penetration test. You can’t attack what you don’t know exists. This tool maps out the entire environment.
